# 脱离鼠标使用VScode（使手敲速度跟上思路/肌肉记忆）

## 定位

### Ctrl + Page（Up/Down）

- 按顺序切换页面

### Ctrl + (Up/Down)Arrow

- 视图上下移动（按行）

### Page（Up/Down）

- 视图上下移动（按页）



### Ctrl + G

- 快速定位到某一行。
- 输入数字视图预览，Enter定位

### Ctrl + （Right/Left）Arrow

- 快速移动光标，整单词跳过。

### Ctrl + Shift + （Right/Left/Up/Down）Arrow

- 移动光标，并选择整个单词/行。

### Home/End

- 光标移动到行首/尾

## 修改

### Ctrl + Shift + K

- 删除整行

### Alt + UpArrow/DownArrow

- 快速将该行上下移动

### Ctrl + [ 或 ]

- 行缩进减少/增加

### Ctrl + /

- 快捷注释行



## 便捷

### Ctrl + Enter

- 在下方插入行，移动光标到下一行。

### Ctrl + |

- 拆分当前页面

## 终端

### Ctrl + Shift + C

- 打开新的外部终端

### Ctrl + J 或 ~

- 查看：切换 终端
