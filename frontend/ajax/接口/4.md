## 3. 用户个人资料管理 API

实现文件：`ajax/mockNode/4.js`
可能使用者：`ajax/example/3个人信息设置.html`
数据存储：`ajax/json/4.json`
文件上传：`ajax/uploads/` (通过 `/uploads` 静态提供)
基础 URL：`http://localhost:3001`

### 端点

#### 获取用户信息

- **方法：** `GET`
- **路径：** `/user-info`
- **描述：** 从 `4.json` 检索当前用户的个人资料数据。
- **请求体：** 无
- **响应：**
  - `200 OK`: 以 JSON 格式返回用户数据对象：
    ```json
    {
      "email": "test@example.com",
      "nickname": "默认用户",
      "gender": 2,
      "intro": "这个人很懒，什么都没留下...",
      "avatar": "/img/avatar.png"
    }
    ```
  - (如果 `4.json` 损坏，可能会出现潜在错误，可能返回默认的空结构)。

#### 更新用户信息 (文本字段)

- **方法：** `POST`
- **路径：** `/user-info`
- **描述：** 更新 `4.json` 中用户个人资料的文本字段（邮箱、昵称、性别、简介）。
- **请求体：** `application/json`
  ```json
  {
    "email": "new.email@example.com",
    "nickname": "更新后的昵称",
    "gender": 1,
    "intro": "更新后的简介。"
  }
  ```
- **响应：**
  - `200 OK`: 如果成功，返回成功消息和更新后的用户数据：
    ```json
    {
      "message": "用户信息更新成功",
      "userData": { ... 更新后的数据 ... }
    }
    ```
  - `400 Bad Request`: 如果必需字段（`email`, `nickname`）缺失、为空或数据类型不正确。
  - `500 Internal Server Error`: 如果写入 `4.json` 失败。

#### 上传用户头像

- **方法：** `POST`
- **路径：** `/avatar-img`
- **描述：** 上传新的头像图片，保存图片，更新用户个人资料，并可选择删除旧头像。
- **请求体：** `multipart/form-data`
  - 字段名：`avatar`
  - 字段值：要上传的图片文件。
- **响应：**
  - `200 OK`: 如果成功，返回新上传头像的路径：
    ```json
    {
      "message": "头像上传成功",
      "avatarUrl": "/uploads/avatar-1678888999000-123456789.jpg"
    }
    ```
  - `400 Bad Request`: 如果：
    - 未检测到文件 (`{ "message": "未检测到上传的文件" }`)。
    - 文件大小超过限制 (5MB) (`{ "message": "文件过大，请上传小于 5MB 的图片" }`)。
    - 文件类型不是图片 (`{ "message": "仅支持上传图片文件!" }` 或类似消息)。
    - 其他 Multer 错误 (`{ "message": "文件上传错误: ..." }`)。
  - `500 Internal Server Error`: 如果在成功上传后将更新的用户数据写入 `4.json` 失败。
