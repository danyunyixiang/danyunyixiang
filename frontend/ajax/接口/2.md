## 2. 图书管理 API (内存存储)

实现文件：`ajax/mockNode/2.js`
可能使用者：`ajax/example/2图书管理ai示例.html`
数据存储：内存数组 (服务器重启时重置)
基础 URL：`http://localhost:3000` (可能与 API 1 冲突)

### 端点

#### 获取所有图书

- **方法：** `GET`
- **路径：** `/books`
- **描述：** 检索当前存储在内存中的所有图书列表。
- **请求体：** 无
- **响应：**
  - `200 OK`: 返回图书对象的 JSON 数组：`[{ "id": 1, "title": "...", "author": "..." }, ...]`。

#### 添加新书

- **方法：** `POST`
- **路径：** `/books`
- **描述：** 向内存列表添加一本新书。自动分配顺序 ID。
- **请求体：** `application/json`
  ```json
  {
    "title": "另一本图书标题",
    "author": "另一位作者"
  }
  ```
- **响应：**
  - `201 Created`: 以 JSON 格式返回新创建的图书对象：`{ "id": 3, "title": "...", "author": "..." }`。
  - `400 Bad Request`: 如果请求体中缺少 `title` 或 `author`。返回 `{ "message": "书名和作者不能为空" }`。

#### 按 ID 删除图书

- **方法：** `DELETE`
- **路径：** `/books/:id` (例如, `/books/2`)
- **描述：** 从内存列表中删除具有指定 ID 的图书。
- **URL 参数：**
  - `id` (整数): 要删除的图书的 ID。
- **请求体：** 无
- **响应：**
  - `204 No Content`: 如果删除成功 (无响应体)。
  - `400 Bad Request`: 如果提供的 `id` 不是有效数字。返回 `{ "message": "无效的图书 ID" }`。
  - `404 Not Found`: 如果未找到具有指定 `id` 的图书。返回 `{ "message": "未找到指定ID的图书" }`。
