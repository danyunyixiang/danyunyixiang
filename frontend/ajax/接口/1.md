# 模拟 API 文档

**注意：** 部分脚本在同一端口上定义了端点（例如，`1.js` 和 `2.js` 都使用端口 3000）。请确保仅运行与您正在测试的示例相关的脚本。

---

## 1. 图书管理 API (简单 JSON 存储)

实现文件：`ajax/mockNode/1.js`
可能使用者：`ajax/example/1图书管理CURD.html`
数据存储：`ajax/json/1.json`
基础 URL：`http://localhost:3000`

### 端点

#### 获取所有图书

- **方法：** `GET`
- **路径：** `/save-data`
- **描述：** 检索存储在 `1.json` 中的所有图书列表。
- **请求体：** 无
- **响应：**
  - `200 OK`: 返回 `1.json` 的 JSON 内容 (例如, `{ "users": [{ "id": 1, "title": "...", "author": "..." }, ...] }`)。
  - `404 Not Found`: 如果 `1.json` 不存在。

#### 添加新书

- **方法：** `POST`
- **路径：** `/save-data`
- **描述：** 向 `1.json` 添加一条新的图书记录。自动分配顺序 ID。
- **请求体：** `application/json`
  ```json
  {
    "title": "新书标题",
    "author": "图书作者"
  }
  ```
- **响应：**
  - `200 OK`: 返回成功消息：`"数据已写入 1.json"`。
  - `500 Internal Server Error`: 如果读取或写入文件失败。

#### 按 ID 删除图书

- **方法：** `DELETE`
- **路径：** `/delete/:id` (例如, `/delete/5`)
- **描述：** 从 `1.json` 中删除具有指定 ID 的图书。
- **URL 参数：**
  - `id` (整数): 要删除的图书的 ID。
- **请求体：** 无
- **响应：**
  - `200 OK`: 返回成功消息：`"数据已删除"`。
  - (文件操作的错误处理可能在发送响应前隐式返回 500，如果读/写失败)。

#### 删除数据文件 (可选/管理性操作)

- **方法：** `DELETE`
- **路径：** `/save-data`
- **描述：** 删除整个 `1.json` 数据文件。
- **请求体：** 无
- **响应：**
  - `200 OK`: 返回 `{ "message": "文件已删除" }`。
  - `500 Internal Server Error`: 如果删除文件失败。
